{%- comment -%} 文档「上一篇 / 下一篇」导航 (按 date 时间排序) 上一篇 = 时间更早(更旧), 下一篇 = 时间更晚(更新) 排序键直接编码 "时间|url|标题", 标题与链接从键中提取, 不再做二次查找, 避免 Jekyll 中 where+first 取错页面对象导致上一篇显示成当前页的问题。 {%- endcomment -%} {%- assign docs = site.pages | where_exp: "p", "p.path contains 'docs/knowledge-docs/'" | where: "layout", "doc" -%} {%- if docs.size > 1 -%} {%- comment %} 构造可排序的键: 时间(YYYYMMDDHHMMSS) + "|" + url + "|" + 标题 {% endcomment -%} {%- assign keys = "" | split: "" -%} {%- for p in docs -%} {%- assign d = p.date | default: "0000-00-00 00:00:00" -%} {%- assign ds = d | date: "%Y%m%d%H%M%S" -%} {%- assign k = ds | append: "|" | append: p.url | append: "|" | append: p.title -%} {%- assign keys = keys | push: k -%} {%- endfor -%} {%- assign keys = keys | sort -%} {%- comment %} 定位当前文章 {% endcomment -%} {%- assign cur = page.url | remove_last: '/' -%} {%- assign idx = -1 -%} {%- for k in keys -%} {%- assign parts = k | split: "|" -%} {%- assign u = parts[1] | remove_last: '/' -%} {%- if u == cur -%}{%- assign idx = forloop.index0 -%}{%- endif -%} {%- endfor -%} {%- if idx >= 0 -%}
