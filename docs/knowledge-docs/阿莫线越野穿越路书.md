# 阿莫线 · 越野穿越路书

> **Akele — Mosika Traverse Route Booklet**
>
> 阿莫线，指四川阿坝州金川县**阿科里乡**至甘孜州丹巴县**莫斯卡村**之间的高海拔越野穿越线路。纯越野段约 22 公里，翻越海拔 4500m+ 垭口，串联情人海、阿科里大草原与"被世界遗忘的孤岛"莫斯卡。越野圈公认难度最高的川西穿越线之一，雨后泥泞段曾让兰德酷路泽、坦克等硬派车型集体陷车，请严肃对待。

| 关键指标 | 数据 |
|---|---|
| 核心越野段 | 约 22 km（土石路） |
| 最高垭口海拔 | 4550 m |
| 建议行程 | 4 天（成都往返） |
| 越野难度 | ★★★★★（雨后更高） |
| 最佳季节 | 5–6 月 / 9–10 月 |
| 穿越段通讯 | 无手机信号 |

*版本日期：2026-08 ｜ 仅供个人参考，出行前请核实最新路况*

## 一、路线总览

**路线走向：**

成都 → 都汶高速/G317 → 金川县城（2135m）→ 撒瓦脚乡（防火卡点登记）→ 情人海（3800m，可选岔路）→ 阿科里乡 → **阿莫线核心段 22km（翻 4550m 垭口）** → 莫斯卡村（3900m，宿）→ 丹巴县城（1860m）→ 返成都

全程铺装 + 越野合计约 900 km（成都往返）。

## 二、分日行程（4 天方案）

### D1 成都 → 金川县城（适应海拔 + 补给）

- **里程/路况**：约 420km，全铺装，车程 7–8h ｜ 宿金川（2135m）
- **路线**：成都 → 都汶高速 → 理县 → G317 → 观音桥镇 → 金川县城
- 要点：
  - 出成都前满油出发，途中在理县或观音桥镇加油、午餐。
  - 抵达金川后完成：**加满油（此后至丹巴前无可靠加油站）**、采购路餐干粮与饮用水、检查胎压与底盘。
  - 金川县城食宿条件完善，当晚早休息，为次日核心穿越蓄力。
  - 时间富余可顺访金川老街、观音桥景区。

### D2 核心穿越日：金川 → 阿科里 → 翻垭口 → 莫斯卡 ⚠️

- **里程/路况**：约 120km，其中越野 22km，用时 6–8h ｜ 宿莫斯卡（3900m，藏寨通铺）
- **路线**：金川 → 撒瓦脚乡（防火登记）→ 情人海 → 阿科里乡 → 垭口 4550m → 莫斯卡村
- 要点：
  - **09:00 前出发。** 撒瓦脚乡设有**森林防火卡点，需停车登记**（携带所有人身份证）。
  - 途经情人海（撒尔足措，3800m）：高原淡水湖，可短停拍照；由此进入阿科里大草原路段，注意路面起伏与牲畜。
  - 阿科里乡为最后补给点：向乡政府或牧民确认当日路况，曾有乡政府劝返单车穿越的先例——**单车雨后不建议强行通过**。
  - **核心段 22km 拆解：**
    - 出阿科里后约 9km 持续陡坡爬升（平均每公里爬升约 80m），土石路、炮弹坑、交叉轴交替；
    - 垭口段海拔 4500–4550m，常有大雾，能见度可能骤降至不足 50m；
    - 翻垭口后约 8km 放坡下切至莫斯卡河谷，湿泥+碎石混合路面，控制车速防侧滑；
    - 全程**无手机信号**，出发前下载离线地图并告知家人预计出山时间。
- **红线提示**：雨后 24 小时内、降雪期、单车无绞盘、未带拖车绳与防滑板——以上任一条满足，就地放弃穿越，原路退回金川或改走铺装路绕行丹巴（金川→丹巴铺装约 95km）。穿越线永远会等下一次，人车安全只有一次。

### D3 莫斯卡（土拨鼠/转山）→ 丹巴县城

- **里程/路况**：约 75km，后 40km 铺装，车程 3–4h ｜ 宿丹巴（1860m）
- **路线**：莫斯卡村 → 丹东乡方向 → 丹巴县城（甲居藏寨 / 中路藏寨）
- 要点：
  - 上午在村周山坡寻找**旱獭（土拨鼠）**——7–9 月最活跃，会主动讨食；**切勿上手触摸，旱獭可传播鼠疫**，远距离投喂拍照即可。
  - 莫斯卡至丹巴约 70km：前段碎石土路弯多路窄、会车困难，出山后接柏油路直达县城。
  - 下午游览甲居藏寨或中路藏寨（碉楼群），宿县城，海拔回落至 1860m。
  - 丹巴加油、洗车、检查底盘有无托底损伤。

### D4 丹巴 → 成都（返程）

- **里程/路况**：约 340km，全铺装，车程 6–7h
- **路线**：丹巴 → G350 熊猫大道 → 小金/巴朗山 或 汶川方向 → 成都
- 要点：
  - 推荐巴朗山线：猫鼻梁观景台打卡四姑娘山；雨季注意落石路段。
  - 赶时间可走丹巴—小金—卧龙—都汶高速一线，隧道多、更稳妥。

## 三、核心段路况与驾驶要点

**典型障碍：**

- **炮弹坑连片**：雨季重型车轮碾压形成，视觉浅实际深，逐一慢速通过；
- **交叉轴**：陡坡+沟槽组合，低速四驱+差速锁按需介入；
- **泥沼段**：雨后表层泥下为湿滑草甸根土，极易陷车（LC、坦克系列均有沦陷待援案例）；
- **急弯+盲坡**：爬升段弯道视线差，鸣笛示意，对讲机报点；
- **涉水**：莫斯卡河谷浅滩过河，探路后低挡匀速通过，不中途停车。

**驾驶纪律：**

- 全程**低速四驱为主**，禁止高速冲坡；
- 车距保持 50m 以上，前车通过障碍后再跟进；
- 陷车第一时间停车、垫防滑板，禁止猛给油越陷越深；
- 大雾垭口段开车灯、雾灯；
- 让行对向当地车辆与牧民摩托——他们更熟悉路况。

> **通过性判断口诀**：雨后看泥、雾天等晴、单车莫入、油满再进、三点前翻垭口（留足白天余量应对意外）。

## 四、车辆与装备清单

**车辆硬性要求**
- [ ] 硬派越野车 / 四驱 SUV（分时或全时四驱）
- [ ] AT 泥地胎以上，磨损过半请换新
- [ ] 备胎 ×1（最好全尺寸）+ 千斤顶 + 拆胎工具
- [ ] 底盘较高，建议带发动机护板

**脱困装备**
- [ ] 拖车绳（≥8t）+ U 型卸扣一对
- [ ] 防滑板 / 脱困板 ×2
- [ ] 电动充气泵、胎压表
- [ ] 绞盘（强烈建议）+ 手套
- [ ] 铁锹、石块垫木

**通讯与导航**
- [ ] 车台 / 手台（穿越段无手机信号）
- [ ] 卫星电话或卫星盒子（单人单车必备）
- [ ] 离线地图：奥维 / 两步路 + 公开轨迹 GPX
- [ ] 充电宝 ×2、车充

**高原人身装备**
- [ ] 羽绒服、抓绒、防水外套（昼夜温差 20°C+）
- [ ] 睡袋内胆（莫斯卡通铺住宿）
- [ ] 氧气瓶 / 便携氧、葡萄糖口服液
- [ ] 常用药：布洛芬、晕车药、肠胃药、创可贴
- [ ] 防晒霜、墨镜、帽子（紫外线极强）
- [ ] 干粮：巧克力、牛肉干、饼干、足量饮水

## 五、风险控制与应急

| 风险项 | 应对预案 |
|---|---|
| 高原反应 | D1 宿金川（2135m）先行适应；穿越日不剧烈运动；头痛及时吸氧+葡萄糖；症状加重的成员不应坚持进山，可在金川/阿科里留守。 |
| 陷车 | 车队保持 2 车以上同行；单车先探路况再通过；陷车垫板自救，勿深踩油门；彻底陷死时等待后车绞盘救援，保留体力与油料。 |
| 天气突变 | 出发前查金川、丹巴两地三日天气；上午天气窗口期过垭口；午后易起雾起雨，12:00 后不建议再爬升垭口段。 |
| 通讯中断 | 穿越段全程无信号。出发前向家人报备路线与预计出山时间；约定"超时 X 小时未联系即报警"。 |
| 野生动物 | 旱獭禁止触摸（鼠疫风险）；不主动接近牦牛群，路遇牲畜减速绕行。 |
| 防火管制 | 撒瓦脚卡点实名登记；全程禁止野外用火、吸烟；春季防火期可能整段封控，出发前致电金川县林草局确认。 |

**救援求助**：紧急情况拨打 110 / 120 / 122；地方救援力量来自金川县、丹巴县；商业救援保险（含直升机救援条款）建议出发前购买。无信号时，约定留守人员到**阿科里乡政府（乡内有电话）**求助是最可靠的求救路径。

## 七、民俗、环保与责任

- **尊重信仰**：经幡、玛尼堆、寺庙不亵玩；转经、转山按顺时针方向；未经允许不对僧俗人物正面拍照。
- **垃圾零留存**：穿越段与营地垃圾全部带出至县城处理；不向海子、河道抛物。
- **不伤害生灵**：土拨鼠只远观投喂（不触碰），不打扰野生动物与家畜。
- **草甸保护**：不随意下道碾压草场——既是生态红线也是牧民纠纷源。
- **低调通过村庄**：村道限速、不鸣笛惊扰牲畜。
- 本路书仅供参考，路况多变；**最终通过判断以现场为准，出行的全部安全责任在参与者本人**。
