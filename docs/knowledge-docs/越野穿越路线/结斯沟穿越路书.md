# 结斯沟穿越 · 越野穿越路书

![结斯沟原始森林冰川](/docs/knowledge-docs/assets/images/结斯沟.png)

> 从小金出发，深入结斯沟原始森林穿越，原始风光与冰川雪山尽收眼底。前半段城市 SUV 可尝试，后半段非铺装路碎石锋利，易刺穿轮胎——考验车辆性能与驾驶技术。

| 关键指标 | 数据 |
|---|---|
| 起点 | 小金县城 |
| 里程 | 约 50 km 深入（往返 100km+） |
| 路况 | 前段林道，后段锋利碎石非铺装 |
| 建议天数 | 1 天 |
| 越野难度 | ★★★★ |
| 最佳季节 | 6–10 月 |
| 通讯 | 全程无手机信号 |

---

## 看点

- **原始森林**：杉林密布，苔藓与溪流相伴，越野车穿行如入绿境
- **冰川雪山**：沟谷尽头冰川近在咫尺，夏季冰舌可见
- **溪谷涉水**：多段溪流浅滩，越野玩水体验

## 驾驶要点

- 后半段碎石锋利易刺胎：**AT 胎必备**，降胎压通过
- 城市 SUV 只建议走前半段，后半段四驱硬派优先
- 全程无信号：提前下载离线地图，携带卫星电话
- 涉水先探底，低挡匀速通过

## 装备

- AT 胎、全尺寸备胎、充气泵
- 卫星电话（无信号区唯一保险）
- 拖车绳、脱困板（雨后泥泞段）
- 防滑链（秋冬垭口积雪）

## 风险提示

- 雨后泥泞打滑，雨季下午易起雾，上午进沟
- 与 [[理小线路书|理小路]] 可组合为 2 日行程：D1 理小路，D2 结斯沟
- 沟内无补给，小金县城采购物资后进入
