# 宝康线 · 越野穿越路书

![宝康线高山海子与垭口](assets/images/宝康线.png)

> 连接邛崃山脉与横断山脉的通道，一道刻在群山之间的越野车辙。宝康线是"想给旅途加点硬度"的人的入门课——靠谱 SUV 就能走，但颠簸、荒凉、圣洁一样不少。

| 关键指标 | 数据 |
|---|---|
| 全程 | 约 150 km（宝兴—康定） |
| 非铺装段 | 约 60 km |
| 最高海拔 | 近 4000 m 垭口 |
| 建议天数 | 1–2 天 |
| 越野难度 | ★★★ |
| 最佳季节 | 6–10 月（秋季赶羊沟最美） |
| 车辆要求 | 靠谱 SUV + 备胎即可 |

---

## 路线走向

宝兴 → 赶羊沟 → 翻越近 4000m 垭口 → 康定

## 看点

- **赶羊沟**：名字土得掉渣，秋天层林尽染，色彩浓烈得像打翻的调色盘，比许多 5A 景区更震撼
- **高山海子**：垭口附近的海子静默倒映流云，荒凉与圣洁并存
- **垭口碎石路**：颠簸到怀疑人生，但每个拐弯都可能撞见新风景

## 实用要点

- 路上几乎没有商业痕迹，午餐自备自热米饭配山风
- 雨后碎石湿滑，控制车速；建议上午通过垭口段
- 适合新手"练手"：难度适中，不硬核但足够野
- 无加油点规划：出发前加满，县城段补油

## 行程参考

- **1 日方案**：宝兴早出发 → 穿越 → 傍晚抵康定（赶时间可行，但不建议雨天）
- **2 日方案**：D1 穿越并露营或宿村落，D2 康定周边（木格措/跑马山）后返程，更从容
