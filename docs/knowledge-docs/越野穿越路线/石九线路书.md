# 石九线 · 越野穿越路书

![石九线垭口贡嘎南坡](assets/images/石九线.png)

> 石棉到九龙之间的一条牧民小道，越野圈称它"石九线"，又称"十穿九不通"。纯越野段约 80 公里，海拔从 2000 米一路浮到 4750 米，峡谷、河流、森林、草甸一天历尽四季。

| 关键指标 | 数据 |
|---|---|
| 全程 | 255 km（石棉—九龙） |
| 纯越野段 | 60–80 km（洪坝穿越纳布厂） |
| 最高海拔 | 鸡丑山垭口 4750 m |
| 耗时 | 全程约 12h，纯开车 8h |
| 建议天数 | 2–3 天 |
| 越野难度 | ★★★★ |
| 最佳季节 | 10 月中–11 月初（金秋）；夏季也可 |
| 通讯 | 穿越段无信号 |

---

## 路线走向

石棉 → 洪坝乡（原始森林+海子）→ 穿越段 → 鸡丑山垭口（4750m）→ 日鲁库草原 → 九龙

## 核心看点

- **洪坝原始森林**：雪松与枫叶交织的拱廊，雪后如童话世界，《小森林》风格随手出片
- **长海子 / 猎塔湖**：蓝宝石般的路边海子，带偏振镜拍"镜面世界"
- **鸡丑山垭口贡嘎南坡**：清晨晴日可见贡嘎全景，含中山峰、金银山、三连峰，无人机视角震撼
- **河谷露营玩水**：沿途多个平坦河谷，草甸厚实，可露营可越野玩水
- **日鲁库草原**：金色草甸+牦牛群

## 路况警示

- 下雪后山谷里有很长积雪路段，但整体难度可控，无暗冰段；四驱+防滑链即可
- 小心石头蹭胎壁；冬季穿越必须结伴，里面无信号
- "十穿九不通"：偶遇修路/塌方，一般中午 12 点放行，出发前打听当日放行情况
- 建议从石棉往九龙方向走（洪坝方向原始森林和海子更美），中午在山上午餐

## 行程参考

- **D1**：石棉 → 洪坝乡 → 穿越段露营（河谷草甸）
- **D2**：垭口日出 → 日鲁库草原 → 九龙（宿九龙，可顺游伍须海/猎塔湖）

## 装备补充

- 防滑链（10 月后强制）、AT 胎、脱困板
- 车载电台（部分路段无信号）
- 贡嘎南坡机位建议带长焦+无人机
