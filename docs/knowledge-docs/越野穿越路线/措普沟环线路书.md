# 措普沟环线 · 越野穿越路书

![措普湖与扎金甲博雪山](/docs/knowledge-docs/assets/images/措普沟环线.png)

> 理塘到巴塘之间的野性支线：搓板路+涉水路段，需四驱车。绕行措普湖邂逅岩羊群，在热坑温泉煮鸡蛋，探访康巴第一圣湖"康珠拉措"。

| 关键指标 | 数据 |
|---|---|
| 起止 | 理塘 ↔ 巴塘段支线 |
| 里程 | 约 180 km |
| 路况 | 搓板路+涉水路段 |
| 建议天数 | 1–2 天 |
| 越野难度 | ★★★☆ |
| 最佳季节 | 6–10 月 |
| 车辆要求 | 四驱车 |

---

## 看点

- **措普湖**：蒂芙尼蓝湖水+扎金甲博雪山，沿栈道环湖徒步，可近距离与岩羊互动
- **热坑温泉**：天然硫磺泉，煮温泉蛋（约 5 元/个），"高原煮蛋"名场面
- **康珠拉措**：康巴第一圣湖，深藏山谷的静谧海子
- **措普寺**：千年古寺，转经祈福

## 路况与驾驶

- 搓板路：控制车速 40–60km/h 左右可减少共振，太快伤悬挂
- 涉水路段：先观察水深与河床，低挡匀速通过，不中途停车
- 岩羊、牦牛随时穿路，减速让行

## 行程建议

- **D1**：理塘 → 措普沟 → 沟口住宿（约 360km 往返含景区，或宿巴塘）
- 可与 [[格聂南线路书|格聂南线]] 衔接：巴塘 → 措普沟 → 理塘 组成 2 日支线

## 补给提示

- 沟口有酒店/营地住宿，海拔约 3200m 相对舒适
- 景区门票/通行费以现场为准，旺季提前预约
- 高反药物、氧气瓶随身（景区内海拔 3500–4200m）
