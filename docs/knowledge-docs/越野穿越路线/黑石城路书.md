# 黑石城 · 越野穿越路书

![黑石城贡嘎群峰](/docs/knowledge-docs/assets/images/黑石城.png)

> 新都桥高尔寺山上的私藏点位，春季无遮挡、视野极致开阔。登顶远眺贡嘎、雅拉神山群峰，拍摄日照金山与星空同框——越野车可直达的贡嘎绝佳机位。

| 关键指标 | 数据 |
|---|---|
| 位置 | 新都桥高尔寺山 |
| 海拔 | 约 4200m |
| 路况 | 非铺装土路可达 |
| 建议天数 | 半天–1 天 |
| 越野难度 | ★★☆ |
| 最佳季节 | 春季（视野最开阔）、秋冬（晴率高） |

---

## 看点

- **贡嘎+雅拉同框**：黑石城是少有的能同时远眺两大神山群峰的点位
- **日照金山**：傍晚贡嘎主峰金光，春季无遮挡
- **星空银河**：海拔高、光害少，夏季银河拱桥横跨雪山
- **黑石地貌**：黑石堆叠的异域感，无人机视角震撼

## 行程建议

- 新都桥午饭后出发 → 下午登顶 → 守日落金山 → 拍星空 → 夜返新都桥
- 或下午出发扎营过夜，次日清晨拍日出+晨雾

## 装备

- 防寒：垭口风大，羽绒服+防风层
- 长焦+三脚架+快门线（星空摄影）
- 露营可选：帐篷、睡袋（-10°C 级别）
- 头灯/营地灯、保温壶

## 风险提示

- 4200m 高反风险，行动放缓
- 垭口大风，注意帐篷固定与器材安全
- 土路雨后泥泞，四驱优先，防滑链备用
