# 丹道环线 · 越野穿越路书

![丹道环线玉科草原](assets/images/丹道环线.png)

> 318 太挤、川藏太远，川西还藏着一条 360 公里的秘境环线——被《中国国家地理》列为"中国十大必驾路线"的丹道环线。碎石路段、高海拔垭口、无人区穿越，它是越野车该去的地方。

| 关键指标 | 数据 |
|---|---|
| 全程 | 约 360 km 环线 |
| 非铺装段 | 约 30%（党岭—玉科为核心越野段） |
| 海拔范围 | 1800m–4500m |
| 建议天数 | 4–5 天 |
| 越野难度 | ★★★☆ |
| 最佳季节 | 6–10 月（7–8 月野花、10 月秋色） |
| 车辆要求 | SUV/越野车（底盘 ≥200mm，建议四驱） |

---

## 路线走向

成都 → 丹巴 → 党岭村（葫芦海）→ 玉科草原 → 道孚 → 墨石公园 → 八美 → 新都桥 → 康定 → 成都

## 分日行程

- **D1**：成都 → 泸定桥 → 丹巴（约 350km，宿甲居藏寨民宿或丹巴县城）
- **D2**：丹巴 → 党岭村 → 葫芦海 → 玉科草原（约 120km，**越野核心段**，宿玉科帐篷营地）
- **D3**：玉科 → 道孚 → 龙灯草原（约 100km，看道孚民居，宿道孚县城）
- **D4**：道孚 → 墨石公园 → 八美 → 新都桥（约 150km，景观密度最高一天，宿新都桥）
- **D5**：新都桥 → 折多山/红海子 → 成都（约 330km，返程）

## 核心看点

- **党岭·葫芦海**：4100m 高山湖，湖水如镜倒映雪峰；党岭村徒步 3–4h 或摩托往返
- **玉科草原**："康巴阿勒泰"，6–8 月野花铺满草甸，深处有天然温泉
- **道孚民居**："康巴第一藏房"，崩科结构冬暖夏凉
- **亚拉雪山**：5820m，"中国最美十大雪山"之一，北坡亚拉友措湖雪峰倒影
- **墨石公园**：中国唯一高原糜棱岩石林，随湿度光照变色，如异域星球

## 越野段详解（D2 丹巴—玉科）

| 路段 | 里程 | 路面 | 难度 |
|---|---|---|---|
| 丹巴→党岭村 | 约 60km | 前 30km 铺装 + 后 30km 碎石 | ★★★☆ |
| 党岭→葫芦海 | 约 15km | 越野土路+徒步 | ★★★★ |
| 党岭→玉科 | 约 60km | 全程碎石+土路，翻 4500m 垭口 | ★★★★ |

- 碎石路降胎压 1.8–2.0bar，四驱低速通过，保持 50m 以上车距
- 党岭村无手机信号，提前下载离线地图
- 党岭至玉科弯急路窄无护栏，夜间绝对不走

## 加油与补给

- **丹巴县城加满油**：丹巴到道孚约 130km 无加油站，碎石段油耗高 30%+，建议带 20L 备用油桶
- 党岭村：无加油站，仅小卖部基础物资，备现金
- 玉科草原：无加油站，民宿提供餐饮
- 道孚县城：完整补给

## 红线提示

- 高反关键点：党岭 3400m、玉科 3800m、垭口 4500m，提前 3 天红景天
- 雨季午后常有雷阵雨，碎石路雨后湿滑，**上午通过越野段**
- 牦牛随时上路，减速等待不鸣笛
- 垃圾全部带走，玉科、党岭生态脆弱
