# 格聂南线 · 越野穿越路书

![格聂神山与格聂之眼](assets/images/格聂南线.png)

> 从理塘到巴塘，翻铁匠山、绕格聂神山、穿热梯河谷、越扎瓦拉垭口——格聂南线被称为"川西最后的雪山荒野"，是越野圈公认的顶级景观穿越线，非铺装路段超过 70%。

| 关键指标 | 数据 |
|---|---|
| 全程 | 约 230 km（理塘—巴塘） |
| 非铺装占比 | 70%+（炮弹坑、碎石、连续涉水） |
| 最高海拔 | 扎瓦拉垭口 4900m+ |
| 建议天数 | 2–3 天 |
| 越野难度 | ★★★★ |
| 最佳季节 | 6–10 月（6 月杜鹃、10 月彩林） |
| 通讯 | 格聂镇—巴塘几乎全程无信号 |

---

## 路线走向

理塘（4014m）→ 铁匠山垭口（4700m）→ 格聂之眼 → 冷古寺（新寺/老寺）→ 热梯河谷 → 夯达营地 → 格木村 → 扎瓦拉垭口（4900m+）→ 劳者龙巴 → 巴塘（2580m）

## 分日建议

- **D1**：理塘 → 铁匠山垭口 → 格聂之眼 → 新冷古寺（宿格聂镇或冷古寺附近，约 60km）
- **D2**：新冷古寺 → 老冷古寺（徒步 1.5h 或村民摩托）→ 热梯河谷 → 夯达营地露营（约 50km，越野精华段）
- **D3**：夯达营地 → 扎瓦拉垭口 → 巴塘（约 120km，后半程转好路）

## 核心看点

- **格聂之眼**：无人机视角如大地瞳孔倒映雪山，6–8 月水草丰美
- **老冷古寺**：千年古寺，金顶红墙，需徒步或坐藏民摩托深入
- **热梯河谷**：原始森林+野花草甸，越野车冲冰河是全段最痛快体验，露营天花板
- **扎瓦拉垭口**：灰黑怪石如异星地表，格聂群峰连排压来，云海在脚下翻涌
- **下则通村野温泉**：徒步 20 分钟泡硫磺泉，直面格聂神山

## 路况与驾驶

- 非铺装超 70%：炮弹坑、碎石、连续涉水贯穿全程
- 硬派四驱或高底盘四驱 SUV 是底线，城市 SUV 会托底
- 涉水路先观察水深，超过半个车轮切勿强过，选浅滩低挡匀速
- 扎瓦拉垭口附近有挂壁窄道，旁边是深渊，雨季会车极难
- 碎石路段降胎压至 1.8–2.0bar，返回铺装路及时补气

## 露营推荐

- **夯达营地**（约 4000m）：帐篷正对格聂神山，日照金山+银河同框的天花板
- **热梯河谷**：草甸铺到天边，越野+野奢露营体验
- **格木村**：穿越途中的村落营地

## 红线提示

1. **高反**：全线海拔 4000–5000m，理塘住宿就会触发高反，提前一周红景天，随身氧气瓶
2. **无信号**：从格聂镇到巴塘几乎全程无信号，提前下载两步路/奥维离线地图，标注关键岔口；强烈建议结队，单车风险大
3. **零补给**：理塘必须加满油，中途无加油站；带足自热米饭、水和能量食品
4. **证件**：无需边防证，身份证必带，沿途有检查站登记
