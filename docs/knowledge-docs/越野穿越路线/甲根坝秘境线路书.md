# 甲根坝秘境线 · 越野穿越路书

![甲根坝贡嘎日照金山](/docs/knowledge-docs/assets/images/甲根坝秘境线.png)

> 甲根坝，被遗忘的隐秘村落，保留着最原生态的藏式民居与田园风光。越野路段直达观景台，正对贡嘎雪壁——清晨 6 点前，当第一缕阳光点燃贡嘎主峰，你会明白为什么老玩家愿意为它凌晨 5 点起床。

| 关键指标 | 数据 |
|---|---|
| 起点 | 甲根坝（新都桥西侧） |
| 秘境 | 提弄 / 德钦观景台 |
| 里程 | 约 120 km（甲根坝往返） |
| 路况 | 非铺装直达观景台 |
| 建议天数 | 1 天 |
| 越野难度 | ★★★ |
| 最佳季节 | 4–5 月（杜鹃）、9–10 月（晴率高） |

---

## 看点

- **贡嘎群峰日照金山**：观景台无遮挡正对贡嘎雪壁，日出金光洒满主峰
- **德钦/提弄秘境**：原始村落+高山草甸，几乎没有游客
- **垭口云海**：清晨云海翻涌，雪山"漂浮"其上

## 关键节奏

- **凌晨 5:00 前出发**，赶日出前抵达观景台
- 越野路段直达：非铺装碎石+草甸，SUV 可走，四驱更稳
- 拍完日照金山下山吃早餐，下午可转新都桥周边

## 装备

- 长焦镜头（200mm+）拍金山特写
- 三脚架、保温壶（垭口清晨气温低）
- 防滑链（秋冬垭口积雪）、充气泵

## 风险提示

- 垭口海拔高，观景别剧烈运动
- 天气窗口短：查好天气预报再定出发日
- 与黑石城同属"贡嘎机位"，可择一或连走
