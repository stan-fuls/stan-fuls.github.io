# 格聂 C 线 · 越野穿越路书

![格聂C线炮弹坑路段](assets/images/格聂C线.png)

> 被称为"川西拆车场"的硬核穿越线。驱车碾过炮弹坑、碎石路、浅冰面，四驱越野车才能从容应对。当抵达格聂之眼外围观景台，感受极致的孤独与自由。

| 关键指标 | 数据 |
|---|---|
| 位置 | 理塘周边环线 |
| 路况 | 炮弹坑、碎石、浅冰面、陡坡 |
| 最高海拔 | 4500m+ |
| 建议天数 | 1–2 天 |
| 越野难度 | ★★★★★ |
| 最佳季节 | 6–10 月 |
| 车辆要求 | 硬派四驱专属 |

---

## 路线特点

- 炮弹坑连片、碎石锋利、部分浅冰面，交叉轴路段频繁
- 途经格聂之眼外围观景台（非主景区视角），更野更孤独
- 全程人迹罕至，是"车辙即道路"的原生态穿越

## 驾驶要求

- **硬派四驱**（分时四驱+低速四驱），AT 胎，绞盘强烈建议
- 炮弹坑逐一慢速通过，交叉轴路段低速四驱+差速锁按需介入
- 浅冰面前先探厚度与附着，不冒险冲冰
- **必须专业领航或跟随有经验的穿越队**，新手勿入

## 装备硬指标

- 绞盘 + 拖车绳（≥8t）+ 防滑板 ×2
- 全尺寸备胎 ×2、充气泵、补胎工具
- 卫星电话/卫星盒子（全程无信号）
- 离线轨迹 GPX（两步路/奥维）

## 风险提示

- 无补给无信号，油料按 1.5 倍规划，理塘满油出发
- 高反风险同上格聂区域，氧气瓶随身
- 单车禁止进入；任何一次陷车救援成本都极高
