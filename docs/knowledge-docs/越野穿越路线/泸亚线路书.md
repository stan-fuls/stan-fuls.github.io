# 泸亚线 · 越野穿越路书

![泸亚线峡谷盘山路](assets/images/泸亚线.png)

> 泸沽湖到稻城亚丁，直线距离仅 100 公里，绕行却要 700 公里。泸亚线用 280 公里的土路把两个"世界"连在一起——一边是摩梭女儿国，一边是藏地神山。老司机口中的"四川天路"。

| 关键指标 | 数据 |
|---|---|
| 全程 | 约 280 km，行车 8h+ |
| 海拔范围 | 2600m–4500m |
| 建议天数 | 2–3 天（含亚丁 1 日游） |
| 越野难度 | ★★★★☆ |
| 最佳季节 | 5–6 月 / 9–10 月 |
| 车辆要求 | 四驱越野车起步 |

---

## 三线怎么选

- **西线（最常走）**：亚丁 → 俄初村 → 屋脚乡 → 俄牙同乡 → 依吉乡 → 前所乡 → 泸沽湖。路况相对成熟，风景与人文兼备。
- **东线**：经蒙自乡、固增乡、瓦厂镇、屋脚乡、前所乡。路线最复杂、岔口多、极易走错，提前做足功课。
- **中线**：蒙自乡经水洛到泸沽湖。2/3 里程在水洛河峡谷穿行，风景单调，但岔口少不易迷路。

## 核心看点

- **俄亚大村**：罕见的纳西族古寨，蜂窝状土掌房依山而建，保留数百年原貌
- **金沙江支流峡谷**：路窄弯急，一侧咆哮河水、一侧松动山崖
- **三怙主神山**：翻过山梁后仙乃日、央迈勇、夏诺多吉在远处显现，跋涉后的抵达感拉满
- **稻城亚丁**：牛奶海、五色海镶嵌雪山之间（建议单独留 1 天）

## 路况警示

- 2020 年部分路段硬化过，但地质变动后仍有大量土路，塌方、落石是常态
- 非四驱越野车不要尝试；雨季（7–8 月）尽量避开
- 临崖无护栏路段：弯道鸣笛、严禁占道超车、提前在会车点避让
- 走东线务必提前下载离线轨迹，分岔多易走错

## 装备补充

- 全尺寸备胎 ×2（碎石扎胎概率高）
- 拖车绳、脱困板（塌方落石段可能用得上）
- 卫星电话/卫星盒子（峡谷段无信号）
- 现金（部分村落无法移动支付）
