# 党岭—玉科穿越 · 越野穿越路书

![党岭玉科垭口碎石路](assets/images/党岭玉科穿越.png)

> 从丹巴党岭村到道孚玉科草原，全程碎石+土路，翻越海拔 4500 米垭口，弯急路窄无护栏。垭口那头的玉科草原被誉为"康巴阿勒泰"，雪山环抱，野花铺地，深处藏着天然温泉——这是整条丹道环线最硬的一段。

| 关键指标 | 数据 |
|---|---|
| 起止 | 丹巴党岭村 ↔ 道孚玉科草原 |
| 里程 | 约 120 km |
| 路况 | 全程碎石+土路，翻 4500m 垭口 |
| 建议天数 | 1 天（或露营 1 晚） |
| 越野难度 | ★★★★ |
| 最佳季节 | 6–10 月 |
| 通讯 | 全程无信号 |

---

## 看点

- **党岭·葫芦海**（岔路可去）：4100m 高山湖，原始森林环抱，湖如明镜倒映雪峰
- **玉科草原**："康巴阿勒泰"，6–8 月紫色黄色野花铺满草甸，溪流蜿蜒
- **天然温泉**：草原深处散布温泉，雾气氤氲，是露营的绝佳地点
- **垭口云海**：4500m 垭口俯瞰雪山草原全景

## 路况详解

- 党岭村至玉科：全程碎石+土路，翻 4500m 垭口，弯急路窄
- 碎石路降胎压至 1.8–2.0bar，四驱低速通过
- 无护栏路段严禁夜间行驶
- 雨季雨后泥泞打滑，留意路面塌方

## 露营与住宿

- **玉科草原帐篷营地**：条件简陋，自带睡袋，围炉看星空
- 草原深处温泉旁可扎营（注意温泉温度与安全）
- 党岭村有村民民宿（条件有限）

## 装备与补给

- 丹巴加满油（至道孚约 130km 无加油站，带备用油桶）
- 党岭村无信号、无加油站，备现金
- 防滑链（垭口秋冬积雪）、拖车绳、充气泵

## 红线提示

- 高反：党岭 3400m、玉科 3800m、垭口 4500m
- 上午通过垭口段，午后雷雨湿滑
- 垃圾全部带出，草甸禁碾压
- 此段是 [[丹道环线路书|丹道环线]] D2 的核心越野段
