# 理小路 S450 · 越野穿越路书

![理小路回头弯](/docs/knowledge-docs/assets/images/理小路.png)

> 被称为"四川版独库公路"的理小路（S450），连续的回头弯与陡坡，既是老司机的驾驶试炼场，也是沉浸式观景台。穿越邛崃山隧道，串联雪山森林，一个弯一个景。

| 关键指标 | 数据 |
|---|---|
| 起止 | 理县 ↔ 小金 |
| 里程 | 约 120 km |
| 路况 | 已部分铺装，含回头弯+陡坡段 |
| 建议天数 | 1 天（顺路） |
| 越野难度 | ★★☆ |
| 最佳季节 | 6–10 月 |
| 车辆要求 | 两驱可走，四驱更从容 |

---

## 看点

- **连续回头弯**：盘旋于云雾山间，每一个弯都能看到不同角度的川西美景
- **远眺四姑娘山**：沿途可远望四姑娘山轮廓线
- **雪山森林**：穿越邛崃山隧道前后景观截然不同，衔接毕棚沟/四姑娘山两大景区

## 行程衔接

- **西进**：成都 → 理县 → 毕棚沟 → 理小路 → 小金 → 四姑娘山
- **东出**：四姑娘山 → 小金 → 理小路 → 理县 → 成都
- 可与 [[结斯沟穿越]] 搭配：理小路走景观，结斯沟走越野

## 实用要点

- 弯多坡陡，控制车速、不越中线；隧道内开灯
- 雨季注意落石与边坡路段
- 沿途补给点少，出发前加满油、备零食饮水
