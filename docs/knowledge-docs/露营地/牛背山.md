# 牛背山营地

![牛背山云海星空](assets/images/牛背山.png)

> 站在云海之上拍星空，前景是贡嘎雪山，背景是银河拱桥——牛背山凭借开阔的 360° 观景平台，被称为"出片率最高"的营地，也是川西云海+雪山+星空的经典组合。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 3666 m |
| 位置 | 雅安荥经县/泸定交界 |
| 到达方式 | 景区化运营，需乘观光车/徒步或预订住宿 |
| 营地设施 | 成熟营地+星空帐篷酒店 |
| 适合人群 | 出片党、怕高反人群优先选择 |
| 最佳季节 | 冬季至春季（云海率高）、秋季 |

---

## 营地体验

- **云海翻涌**：360° 云海平台，云海之上看日出日落
- **贡嘎+银河**：夏季银河拱桥横跨贡嘎雪山，前景独特
- **相对低海拔**：3666m 高反风险低于 4000m+ 营点，适合初次体验者

## 到达路线

成都 → 雅安 → 荥经 → 牛背山景区（约 4–5h），换乘景区观光车/徒步上山

## 装备建议

- 山顶风大夜冷：羽绒服+防风层、冬季睡袋
- 摄影：广角+长焦、三脚架、快门线
- 保温壶、头灯、充电宝

## 注意事项

- 景区化运营：住宿与门票提前预约（旺季紧张）
- 山顶昼夜温差大，保暖优先
- 云海率看天气窗口，行前查云海预报
- 高反预案照旧：氧气瓶随身
