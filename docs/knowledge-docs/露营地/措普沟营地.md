# 措普沟营地

![措普湖营地](assets/images/措普沟营地.png)

> 措普沟沟口住宿点与沟内营地：措普湖蒂芙尼蓝湖水、扎金甲博雪山、热坑温泉煮蛋、与岩羊互动。海拔约 3200 米起，是川西少见的高原湖泊+温泉营地组合。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 3200 m（沟口）– 4200 m（沟内） |
| 位置 | 甘孜州巴塘县措普沟 |
| 到达方式 | 理塘/巴塘出发，[[越野穿越路线/措普沟环线路书\|措普沟环线]] 直达 |
| 营地设施 | 沟口酒店/营地；沟内需自带露营装备 |
| 适合人群 | 四驱自驾露营玩家 |
| 最佳季节 | 6–10 月 |

---

## 营地体验

- **措普湖**：蒂芙尼蓝湖水+扎金甲博雪山倒影，栈道环湖徒步
- **热坑温泉**：天然硫磺泉煮温泉蛋（约 5 元/个），高原名场面
- **岩羊互动**：湖边岩羊群不怕人，可远距离观察
- **康珠拉措**：康巴第一圣湖，深藏山谷的静谧海子

## 到达路线

- 巴塘方向：巴塘 → 措普沟（约 80km）
- 理塘方向：理塘 → 措普沟（约 180km，搓板路+涉水，需四驱）

## 装备建议

- 沟内露营：帐篷+冬季睡袋（夜间低温）
- 温泉：泳衣、毛巾
- 涉水路段车辆装备：充气泵、拖车绳
- 防高反：氧气瓶、葡萄糖

## 注意事项

- 沟内搓板路+涉水：四驱车优先，涉水先探底
- 岩羊等野生动物保持距离，不投喂
- 门票/自驾通行费以景区现场为准，旺季提前预约
- 垃圾全部带走，保护湖泊生态
