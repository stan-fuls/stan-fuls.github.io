# 孟屯河谷营地

![孟屯河谷森林溪流](/docs/knowledge-docs/assets/images/孟屯河谷.png)

> 海拔仅 2200 米、植被茂密、高反风险低——孟屯河谷是"川西星空露营入门第一课"，也是带娃家庭最稳的选择。代价是银河亮度略逊高海拔，这是物理规律，没有两全其美。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 2200 m |
| 位置 | 阿坝州理县孟屯河谷 |
| 到达方式 | 成都出发约 3h，铺装路+短土路 |
| 营地设施 | 成熟营地、客栈、农家乐齐全 |
| 适合人群 | 新手、亲子、怕高反人群 |
| 最佳季节 | 5–10 月 |

---

## 营地体验

- **入门星空**：远离城市光害，银河可见（强度低于高海拔）
- **森林溪流**：河谷两岸杉林密布，溪水潺潺，夏季清凉
- **低风险**：2200m 基本无高反，适合作为高原露营试水

## 到达路线

成都 → 都汶高速 → 理县 → 孟屯河谷（约 3h）

## 装备建议

- 基础露营套装：帐篷、睡袋（夏季 10°C 级别即可）
- 户外桌椅、气炉、食材（营地可补给）
- 驱蚊液（夏季河谷蚊虫）、防水鞋

## 注意事项

- 雨季（7–8 月）注意河谷水位上涨，勿在河滩扎营
- 部分营地收费，提前确认设施（厕所/水源）
- 垃圾带走，保护河谷生态
- 可搭配周边：毕棚沟、甘堡藏寨一日游
