# 姑弄村营地

![姑弄村雅拉雪山](/docs/knowledge-docs/assets/images/姑弄村.png)

> 直面雅拉雪山，被驴友称为"川西露营天花板"。塔公草原旁的姑弄村，雪山近景毫无遮挡——喜欢雪山近距离接触的玩家首选。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 3500 m |
| 位置 | 甘孜州康定塔公镇姑弄村 |
| 到达方式 | 新都桥/塔公出发约 30–40 分钟，铺装路+短土路 |
| 营地设施 | 基础营地/村民空地，条件简单 |
| 适合人群 | 雪山近景爱好者、自驾露营 |
| 最佳季节 | 6–10 月 |

---

## 营地体验

- **雅拉雪山近景**：正对雅拉金字塔形雪峰，日照金山无遮挡
- **草甸溪流**：村周河谷草甸开阔，溪流旁扎营
- **塔公人文**：就近可游塔公寺、木雅大寺，遥望贡嘎

## 到达路线

新都桥 → 塔公 → 姑弄村（约 30–40 分钟）

## 装备建议

- 帐篷+秋季睡袋（3500m 夜间凉）
- 摄影：长焦拍雅拉特写、广角拍草甸全景
- 头灯、保温壶、防高反药物

## 注意事项

- 部分区域为牧民草场，扎营前与村民沟通、付费
- 尊重当地信仰：不亵玩经幡玛尼堆
- 垃圾全部带走
- 可与 [[鱼子西]] 或塔公草原日落组合一日行程
