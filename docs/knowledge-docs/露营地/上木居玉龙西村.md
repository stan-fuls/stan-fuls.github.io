# 上木居与玉龙西村营地

![上木居村贡嘎山乡](/docs/knowledge-docs/assets/images/上木居玉龙西村.png)

> 冷嘎措与子梅垭口的"桥头堡"——上木居村、玉龙西村、帮木吉德村是贡嘎西坡环线的三个补给节点。藏家客栈、小卖部、餐饮齐全，露营或住宿皆可，是登冷嘎措、守子梅垭口的中转营地。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 3700–3900 m |
| 位置 | 康定贡嘎山乡（上木居/玉龙西/帮木吉德） |
| 到达方式 | 新都桥 → 甲根坝 → 沙德 → 贡嘎山乡方向（铺装为主） |
| 营地设施 | 藏家客栈+民宿+小卖部；可村民空地扎营 |
| 适合人群 | 冷嘎措/子梅垭口露营中转 |
| 最佳季节 | 4–5 月、9–10 月 |

---

## 营地体验

- **贡嘎西坡门户**：三村环抱，抬头即可见贡嘎群峰
- **泉华滩**（玉龙西村）：钙化池如黄龙缩影，轻徒步可近望雪山
- **藏家烟火**：牦牛肉火锅、酥油茶，听村民讲雪山故事
- **休整补给**：为登冷嘎措/子梅垭口做最后物资准备

## 到达路线

成都 → 康定 → 新都桥 → 甲根坝 → 沙德 → 上木居/玉龙西村

## 装备建议

- 客栈住宿即可（150 元/晚级含早晚餐，以现场为准）
- 扎营需自带帐篷睡袋（村民空地协商付费）
- 登山杖、徒步鞋（登冷嘎措用）
- 氧气瓶、防寒衣物（夜宿 3700m+）

## 注意事项

- 三村为登高前置营地：先在村中适应一晚再上 4500m 营地
- 骑马/摩托价格先谈清楚（往返条款明确）
- 尊重藏家习俗，拍摄村民前征得同意
- 衔接 [[冷嘎措]]、[[子梅垭口]] 组成贡嘎环线
