# 格聂·夯达营地

![夯达营地格聂神山](/docs/knowledge-docs/assets/images/格聂夯达营地.png)

> 帐篷正对格聂神山，夜里银河从峰顶升起——"神山+银河"同框的露营天花板。位置在格聂主峰南面，是离神山最近的营地之一。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 4000 m |
| 位置 | 格聂南线，格聂主峰南坡 |
| 到达方式 | 越野车沿 [[越野穿越路线/格聂南线路书\|格聂南线]] 直达 |
| 补给/信号 | 无补给、无信号 |
| 适合人群 | 硬核玩家 |
| 最佳季节 | 6–10 月 |

---

## 营地体验

- **日照金山**：傍晚格聂神山被霞光染金，近距离的压迫感无以复加
- **星空银河**：无光害，银河从格聂峰顶升起，夏季尤为震撼
- **野花草甸**：6–8 月营地周边野花盛放，草甸绵延至雪山脚下

## 到达路线

理塘 → 铁匠山垭口 → 格聂之眼 → 新冷古寺 → **夯达营地**（格聂南线越野精华段）

## 装备建议

- 帐篷（防风抗寒，-5°C 级别睡袋）
- 气炉+高山气罐（高海拔烹饪）
- 充电宝、头灯、保温壶
- 氧气瓶（4000m 海拔）

## 注意事项

- 全程无信号无补给：物资在理塘备齐，垃圾全部带出
- 格聂南线非铺装超 70%，硬派四驱或高底盘四驱 SUV
- 高反适应后再露营，避免剧烈活动
- 尊重当地：营地远离寺庙与牧民帐篷区
