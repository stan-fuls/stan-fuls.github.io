# 子梅垭口营地

![子梅垭口贡嘎日落金山](assets/images/子梅垭口.png)

> 贡嘎山最大的观景平台，海拔 4500 米，距贡嘎主峰仅 5 公里——站在垭口与蜀山之王遥遥相望，是欣赏贡嘎日落金山、云海佛光的绝佳之地。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 4500 m |
| 位置 | 康定贡嘎山乡子梅村 |
| 到达方式 | 自驾 SUV 可到（碎石盘山路） |
| 门票 | 免费（全天开放） |
| 营地设施 | 2026 年新建星空营地：双人帐篷约 380 元/晚（含睡袋、取暖炉、摄影指导） |
| 适合人群 | 摄影党、自驾露营玩家 |

---

## 营地体验

- **日落金山**：正对贡嘎主峰，角度最端正的观景平台，夕阳把雪山染成金红
- **云海佛光**：天气配合时云海翻涌、佛光乍现
- **星空银河**：凌晨 2 点银河从贡嘎上空升起，流星划过雪峰

## 到达路线

成都 → 康定 → 新都桥 → 甲根坝 → 上木居村 → 子梅垭口

- 全程柏油路至村口，垭口为碎石盘山路，SUV 可走
- 或乘成都→康定大巴转拼车（约 150 元/人）

## 装备建议

- 垭口风大：防风冲锋衣+抓绒+羽绒
- 露营或住星空营地：自带 -10°C 睡袋更稳妥
- 长焦+三脚架、防滑链（秋冬垭口积雪）
- 氧气瓶、保温壶

## 注意事项

- 4500m 高反：行动放缓，症状明显立即下撤至上木居村
- 垭口碎石路雨后泥泞，四驱优先
- 可搭配 [[冷嘎措]]、[[上木居与玉龙西村|玉龙西村泉华滩]] 组成 2–3 日贡嘎环线
- 垃圾全部带走
