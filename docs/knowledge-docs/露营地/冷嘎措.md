# 冷嘎措营地

![冷嘎措贡嘎倒影](/docs/knowledge-docs/assets/images/冷嘎措.png)

> 海拔 4500 米的冰斗型海子，缺口正对贡嘎主峰，湖面如镜倒映贡嘎 13 座雪峰——"神山之镜"。湖边扎营看日照金山倒影与银河，是川西最苦也最值的一夜。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 4500 m（湖边） |
| 位置 | 康定贡嘎山镇玉龙西村/帮木吉德村上方 |
| 到达方式 | 徒步或骑马上山（玉龙西村或帮木吉德村出发） |
| 营地费用 | 湖边平地扎帐约 30 元/人；藏民大帐篷约 80 元/人 |
| 补给/信号 | 湖边有小卖部（泡面、八宝粥），无信号 |
| 适合人群 | 徒步+露营玩家 |

---

## 营地体验

- **贡嘎倒影**：晴日湖面如镜，13 座雪峰倒影同框，日出日落时分最动人
- **星空**：夜间气温接近 0°C，但银河倾泻而下的震撼值回票价
- **煨桑经幡**：藏民在湖边煨桑祈福，经幡随风飘动

## 到达路线

成都 → 康定 → 新都桥 → 甲根坝 → 上木居/玉龙西村 → 徒步或骑马至湖边

- 玉龙西村方向：徒步/骑马上山
- 帮木吉德村方向：可骑马+徒步结合

## 装备建议

- 羽绒服、抓绒、防风外套（夜间接近 0°C）
- 高山帐篷+冬季睡袋、防潮垫
- 头灯、保温壶、氧气瓶、葡萄糖
- 摄影：长焦+三脚架+快门线（倒影与星空）

## 注意事项

- 4500m 高反风险高：提前适应，初到勿剧烈运动
- 骑马务必谈好价格与往返条款（马帮为主）
- 湖水保护：不在湖边清洗餐具，垃圾全部带下山
- 最佳季节 4–5 月（杜鹃）、9–10 月（晴率高），避开 7–8 月雨季
