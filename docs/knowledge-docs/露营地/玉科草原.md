# 玉科草原营地

![玉科草原野花牧场](/docs/knowledge-docs/assets/images/玉科草原.png)

> 被誉为"康巴阿勒泰"的玉科草原，海拔 3800 米，雪山环抱的高原牧场。6–8 月野花铺满草甸、溪流蜿蜒其间，草原深处散布天然温泉——丹道环线上的露营绝佳点。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 3800 m |
| 位置 | 甘孜州道孚县玉科草原 |
| 到达方式 | 沿 [[越野穿越路线/丹道环线路书\|丹道环线]] 党岭方向穿越到达（越野） |
| 营地设施 | 民宿/帐篷营地，条件简陋，自带睡袋 |
| 补给/信号 | 无加油站，民宿提供餐饮，信号弱 |
| 适合人群 | 越野+露营玩家 |

---

## 营地体验

- **野花草甸**：6–8 月紫色黄色野花铺满大地，牦牛马匹悠闲吃草
- **天然温泉**：草原深处温泉雾气氤氲，泡汤观星
- **雪山环抱**：四围雪峰环列，清晨云雾缭绕如仙境

## 到达路线

丹巴 → 党岭村 → 翻 4500m 垭口 → 玉科草原（越野段，约 120km）

## 装备建议

- 冬季级别睡袋（夜间低温）+ 防潮垫
- 泡温泉：泳衣+毛巾（天然野温泉）
- 防高反：氧气瓶、葡萄糖（3800m）
- 露营灯、保温壶

## 注意事项

- 抵达路线为碎石越野段：丹巴满油出发，带备用油桶
- 无信号区域，离线地图必备
- 温泉水温注意烫伤，不独自深入
- 草甸生态脆弱，垃圾全部带走，禁碾压草场
