# 鱼子西营地

![鱼子西360度观景台](/docs/knowledge-docs/assets/images/鱼子西.png)

> 新都桥的 360° 网红观景平台，贡嘎雪山和雅拉雪山尽收眼底。夕阳普照下仿佛在凡间与仙境之间切换，夜里银河悬于雪山之上——川西露营摄影的入门必选项。

| 关键信息 | 数据 |
|---|---|
| 海拔 | 约 4100 m |
| 位置 | 康定新都桥鱼子西村山顶 |
| 到达方式 | 新都桥出发约 1h；导航"曲莫贡"，柏油-水泥-碎石路直达 |
| 补给/信号 | 山顶无商业，信号弱 |
| 适合人群 | 摄影党、情侣、露营新手进阶 |
| 最佳季节 | 6–10 月（银河季）、秋季彩林 |

---

## 营地体验

- **双雪山同框**：贡嘎+雅拉一左一右，360° 无死角
- **日落与银河**：查好日落时间上山，拍完金山拍银河
- **轻松可达**：车可直接开到平台，是新都桥周边最容易的高海拔营点

## 到达路线

新都桥 → 鱼子西村 → 曲莫贡方向盘山（柏油+水泥+碎石，约 1h）

## 装备建议

- 防高反：氧气瓶、葡萄糖；4100m 行动放缓
- 防风保暖：山顶风大，羽绒+冲锋衣
- 摄影：广角+长焦、三脚架、快门线
- 露营：帐篷+冬季睡袋（或住山下民宿次日早早上山）

## 注意事项

- 海拔 4100m，初到高原者建议先在新都桥适应一晚
- 节假日人多，观景台机位紧张，错峰前往
- 山顶无厕所无补给，山下解决再上山
- 垃圾全部带走，草甸禁碾压
