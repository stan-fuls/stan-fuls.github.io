## 四、快速选择指南

- **第一次去川西** → 宝康线或丹道环线入门，宿玉科草原、姑弄村
- **想挑战经典** → 格聂南线或泸亚线，营选夯达、冷嘎措、子梅垭口
- **资深玩家** → 石九线、格聂 C 线、阿莫线，硬派四驱+卫星通讯+结队是底线
- **带娃/怕高反** → 孟屯河谷、牛背山

## 通用铁律

1. **油满再进**：进山前加满油，长无油区带备用油桶
2. **三点前翻垭口**：留足白天余量应对意外
3. **穿越线永远会等下一次**：人车安全只有一次
