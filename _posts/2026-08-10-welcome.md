这是我的第一篇博客文章，欢迎来到我的知识分享平台！

## 关于这个平台

这个平台基于 **Jekyll** 和 **GitHub Pages** 构建，用于分享技术知识、学习笔记和日常工作心得。

### 主要功能

- **博客文章**：分享技术心得和学习笔记
- **文章归档**：按时间线浏览所有文章
- **文档中心**：通过独立的 GitHub 仓库管理技术文档，Web 端提供浏览和检索
- **支持数学公式**：使用 Mathjax 渲染，例如 $$E = mc^2$$
- **支持图表**：Mermaid 流程图和 Chart.js 数据图表

### 技术栈

| 层级 | 技术 |
|------|------|
| 静态站点 | Jekyll + Liquid 模板 |
| 样式 | SCSS / CSS3 |
| 交互 | Vanilla JavaScript |
| 文档存储 | GitHub API + 独立仓库 |
| 部署 | GitHub Pages |
| 图表 | Mermaid + Chart.js |
| 公式 | MathJax |
